Floxac — تطبيق شبكة اجتماعية كامل يعمل بدون خادم
=================================================

الملفات
- index.html              التطبيق كاملًا (الأيقونة مضمّنة داخله، فتظهر حتى لو فتحته وحده)
- manifest.webmanifest    ملف تثبيت التطبيق (PWA)
- sw.js                   العمل بدون إنترنت
- icon.svg                الأيقونة الأساسية
- icon-192.png / icon-512.png / icon-maskable-512.png   أيقونات أندرويد والكمبيوتر
- apple-touch-icon.png    أيقونة الآيفون والآيباد
- favicon-32.png / favicon.ico   أيقونة تبويب المتصفح
- تشغيل-Floxac.bat (ويندوز) / تشغيل-Floxac.command (ماك) / تشغيل-محلي.txt

التشغيل
1) أسرع طريقة: افتح index.html مباشرة في Chrome أو Edge أو Safari.
2) للتثبيت كتطبيق: شغّل تشغيل-Floxac.bat (ويندوز) أو تشغيل-Floxac.command (ماك)، أو من الطرفية: python3 -m http.server 8080
   ثم افتح http://localhost:8080 واضغط "تثبيت" من شريط العنوان.
   على الجوال: ارفع المجلد كاملًا إلى GitHub Pages أو Netlify أو Cloudflare Pages، افتح الرابط، ثم "إضافة إلى الشاشة الرئيسية".
   ملاحظة ماك: إن لم يعمل ملف .command نفّذ مرة واحدة: chmod +x تشغيل-Floxac.command

المميزات
حسابات (تسجيل/دخول)، منشورات بصور وفيديو، قصص ٢٤ ساعة، ريلز، إعجابات وتفاعلات، تعليقات، إعادة نشر، حفظ، متابعة،
رسائل خاصة، مكالمات صوتية/مرئية تجريبية (ميكروفون وكاميرا الجهاز فقط)، إشعارات، بحث ووسوم، عربي/إنجليزي،
فاتح/داكن، نسخة احتياطية واستيراد.

ملاحظات مهمة
- البيانات محفوظة على نفس الجهاز والمتصفح (IndexedDB). استخدم الإعدادات > تصدير نسخة احتياطية للنقل بين الأجهزة.
- المشاركة الحقيقية بين أجهزة مختلفة تحتاج خادمًا (Backend)، والمكالمات تجريبية ولا تتصل بشخص آخر.
- الحسابات التجريبية (Nour / Layla / Omar) تردّ تلقائيًا على الرسائل.
